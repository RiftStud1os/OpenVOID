# OpenVOID
## About
OpenVOID is an open-source Unity project that aims to recreate the movement and mechanics in the Dishonored franchise by Bethesda and Arkane Studios. OpenVOID is inspired by Arkanes' in-house VOID Engine, which was used to build Dishonored 2 and Dishonored: Death of the Outsider. OpenVOID should act as a framework for other Unity projects inspired by the Dishonored franchise.
## Development
OpenVOID is very early on in development, and due to my inexperience with C# and Unity its code will be quite rough, so help would be quite appreciated. THIS PROJECT WILL NOT BE VIBECODED, however AI will be used as a means of helping debug my code, as said before, I am very inexperienced with C# code and Unity, so I will use AI to help me find issues that I wouldn't otherwise see. I plan on releasing OpenVOID as an open alpha when movement mechanics are finished.
